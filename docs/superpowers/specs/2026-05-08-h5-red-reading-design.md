# H5 作品设计方案：《信仰有声——习近平的七年知青岁月》

## 项目背景

参加「红心阅动，信仰有声」红色经典阅读活动，阅读书目为《习近平的七年知青岁月》(中央党校采访实录编辑室)，制作 H5 作品展示阅读成果。

## 一、整体形态

- **类型**：纵向滚动时间线叙事 H5，单页应用
- **页面结构**：封面 → 时间线（7 个年份卡片：1969-1975）→ 底部结束
- **导航方式**：自然上下滑动浏览 + 底部固定时间轴快速跳转
- **部署方式**：纯静态 HTML 文件 + 资源，部署至 CDN/服务器

## 二、视觉基调

- **风格**：庄重红色党建风格
- **主色**：深红底（#8B1A1A → #C41E3A 渐变），金色点缀（#D4A843 / #FFD700）
- **字体**：标题用思源宋体（Noto Serif SC），正文用思源黑体（Noto Sans SC）
- **视觉元素**：党徽、红旗、五角星、光芒线、红绸带等党建符号
- **质感**：背景微纹理，整体庄重典雅不失现代感

## 三、页面结构

### 封面页
- 活动名称：红心阅动，信仰有声
- 书名：习近平的七年知青岁月
- 副标题：中央党校采访实录编辑室
- 党徽 + 红色绸带装饰
- 「开始阅读」按钮 → 点击滚动至时间线

### 时间线卡片 ×7（1969—1975）
每张卡片包含：
1. **年份大标题** — 醒目的年份数字
2. **事件摘要** — 该年 2-3 个关键经历概述
3. **书中金句** — 一句原话引用，打字机效果呈现
4. **受访者点评** — 采访对象的回忆/评价片段
5. **成长感悟** — 从该年经历中获得的成长与转变
6. **照片/插画位** — 占位区域，预留视觉素材

卡片间以垂直时间轴线条串联，滚动时当前年份在时间轴上高亮。

### 快速跳转
- 底部固定时间轴条，7 个年份圆点标识
- 点击圆点滚动至对应年份卡片
- 当前位置高亮

## 四、动效方案（适度级别）

- 封面标题：轻微呼吸/光泽动画
- 卡片进场：fadeInUp（从下方淡入上移），滚动触发
- 金句：打字机逐字出现效果
- 时间轴进度：随滚动填充/高亮
- 过渡流畅，不花哨，保持庄重基调

## 五、音频

- 《我的祖国》纯音乐版，页面加载后用户首次交互触发
- 循环播放，提供静音/取消静音切换按钮
- 按钮位置：右上角或底部固定

## 六、技术实现

- **技术栈**：纯静态 HTML + CSS + 原生 JavaScript，单文件结构
- **滚动体验**：CSS Scroll Snap 或 Intersection Observer 驱动
- **动效**：CSS Animation + Intersection Observer 触发
- **响应式**：以移动端为主（375-414px 宽），兼顾 PC 端
- **资源策略**：字体用 Google Fonts CDN，图片内联 Base64 或本地引用，音频远程引用
- **浏览器兼容**：现代浏览器（Chrome、Safari、微信内置浏览器）

## 七、内容来源

- 源材料：466 页扫描版 PDF《习近平的七年知青岁月》
- 提取方式：PaddleOCR 逐页识别中文内容，输出 Markdown
- 内容组织：AI 梳理提炼为七个年份的结构化卡片内容
